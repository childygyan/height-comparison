# Height Comparison & Height Calculator

A free online **height calculator** for comparing, converting, and understanding
any height — centimeters, feet/inches, growth percentiles, and predicted adult
height for children.

**Try it live: https://height-calculator.net**

## What it does

- **Height unit converter** — two-way conversion between cm, meters, feet, and
  inches. Type in either unit, the other updates instantly.
- **Height percentile calculator** — see where a child's height falls for their
  age and sex, using the CDC 2000 stature-for-age reference and the WHO Child
  Growth Standards (ages 0–5).
- **Child height predictor** — estimates adult height from parents' heights
  using the mid-parental formula, shown as a range (±8.5 cm). It does not
  extrapolate beyond the data.
- **Height comparison** — compare heights side by side (people, characters,
  objects) on one chart.

## Data & methodology

- Growth references: **CDC 2000** stature-for-age and **WHO 0–5y** anthropometry
  (official sources, cross-validated where possible).
- Percentiles use the LMS method. The predictor is a statistical estimate, not
  a medical diagnosis.
- Every tool page carries a **medical disclaimer**: for concerns about a
  child's growth, talk to a pediatrician.

Details: https://height-calculator.net/methodology/

## How to use

1. Open https://height-calculator.net
2. Pick a tool: converter, percentile, predictor, or comparison.
3. Enter a height (and age/sex where asked).
4. Read the result — results update live as you type.

## FAQ

**Is it free?**
Yes — all calculator tools are free to use.

**How accurate is the height predictor?**
It's a population-based statistical estimate (mid-parental formula, ±8.5 cm).
Individual growth varies; it's not a medical prediction.

**Which units are supported?**
Centimeters, meters, feet, and inches — with automatic two-way conversion.

**Does it work on mobile?**
Yes, the site is mobile-first and works on phones, tablets, and desktops,
with a dark mode option.

**Is my data stored?**
Calculations run in your browser. See the privacy policy on the site for
details.
